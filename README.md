# CallNChat

Private two-person messenger for iPhone: chat, voice/video calls, photos, docs and location, with no
owned server. Peers find each other over public Nostr relays and talk directly over WebRTC.
Full roadmap: [docs/PLAN.md](docs/PLAN.md).

Status: **Phase 0 — foundation** (scaffold, tooling, CI, iOS build pipeline).

## Stack

Expo SDK 58 · React Native 0.88 · TypeScript (strict) · Expo Router (`src/app/`) · Jest (`jest-expo`)
· ESLint (flat, `eslint-config-expo`) + Prettier.

## Commands

```bash
npm install
```

```bash
npm run check        # lint + format check + typecheck + tests
```

```bash
npm start            # Metro for a dev-client build (Expo Go is not supported)
```

```bash
npm run ios          # local Debug build on a Mac with Xcode
```

## Installing on iPhone without a Mac ($0)

1. GitHub → Actions → **iOS build** → _Run workflow_ (or push a `v*` tag).
2. Download the `CallNChat-unsigned-ipa` artifact and unzip it to get `CallNChat-unsigned.ipa`.
3. Install it with [SideStore](https://sidestore.io) using a free Apple ID. SideStore re-signs it
   and refreshes the 7-day signature in the background.

## Layout

```
src/app/        Expo Router screens (every file is a route — keep tests and helpers out)
src/ui/         design system (theme tokens, light/dark)
src/__tests__/  screen tests
docs/PLAN.md    architecture + phased plan
```

`ios/` is generated by `expo prebuild` and is not committed.
